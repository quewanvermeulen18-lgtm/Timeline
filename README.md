# Bible Timeline

An interactive timeline of the Bible, from the undated early chapters of Genesis through Revelation. It is a single static HTML file with no build step.

## Use it

Open `index.html` in any browser. To put it online, turn on GitHub Pages under **Settings → Pages** (branch `main`, folder `/ (root)`).

## What it does

- Zoomable horizontal timeline with era bands, events, lifespans, reigns, prophets and when books were written
- A chronological list grouped by era
- Search and category filters
- Add, edit and delete your own entries (they save in your browser)
- Copy, download or load your timeline as JSON to move it between devices

Dates follow one widely used conservative chronology and are marked approximate where scholars disagree. Edit any entry to match the chronology you prefer.
